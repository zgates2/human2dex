# Human2Dex

Academic project website: Dexterous Robot Learning from Wrist-Centric Human Demonstrations.

## Updating the website

- Edit `index.html` for text, video references, and experiment results.
- Edit `styles.css` for presentation and responsive layout.
- Edit `app.js` for video interactions.
- Replace files under `assets/` to update videos, figures, or the manuscript.

Push changes to `main` to publish through the GitHub Pages workflow. In repository Settings → Pages, select GitHub Actions as the publishing source.

## Local preview

Run `python3 -m http.server 4173` in this folder, then visit http://localhost:4173.

Anonymous author information is retained from the provided manuscript. All media belongs to the Human2Dex project. Page layout is inspired by https://dex-umi.github.io/.
